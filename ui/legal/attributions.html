Runtime and development dependencies

  • Node.js — JavaScript runtime.
  • Express — HTTP application framework.
  • Cheerio — HTML parsing and querying.
  • Playwright and @sparticuz/chromium — browser automation/runtime components.
  • ipaddr.js — IP address parsing and range checks.
  • dotenv — environment variable loading during local development.
  • Tailwind CSS — utility-first CSS build tooling.
